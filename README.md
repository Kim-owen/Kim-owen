# CrypTopUp

A Node.js app to purchase mobile data using USDT (crypto) via USSD. Integrates Africa's Talking, MongoDB, Web3.js, and Reloadly.

## Features
- USSD menu (Africa's Talking)
- MongoDB for users & transactions
- Web3.js to monitor USDT payments
- Reloadly API for data top-up

## Setup
1. Install dependencies: `npm install`
2. Set up `.env` with your API keys and MongoDB URI
3. Start server: `npm start`
4. Use Ngrok to expose port 3000 for USSD testing

## Note
- Uses dummy API keys and addresses for demo.
